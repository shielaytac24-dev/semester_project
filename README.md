# Semester Project

## Summary
This project is a Flutter Web application developed for our semester project. It includes a welcome screen and a login screen as the initial features.

## Current Stack
Flutter Web and Dart. REST API and PostgreSQL are planned for future development.

## Run Locally
1. Install Flutter SDK and Google Chrome.
2. Open the project folder in VS Code.
3. Open the terminal and run:

```bash
flutter pub get
flutter run -d chrome
```
